# MabiPNG Studio

마비노기 그림대화 PNG를 만들고 변환하고 편집하는 Windows용 Rust GUI입니다.
프로그램 실행에는 Python이나 Rust 설치가 필요하지 않습니다. 소스 빌드에는 Rust 도구 체인이 필요합니다.

## 주요 기능

- 여러 PNG 열기 및 드래그 앤 드롭, Windows 클립보드 이미지 불러오기
- 일반 이미지를 4색·2비트 그림대화 PNG로 변환
- 너비 96~256픽셀, 높이 96픽셀의 빈 그림대화 생성
- 기존 그림대화의 팔레트·작성자 편집, author에 대응하는 authid 생성
- 4색 개별 HEX 입력 및 색상 선택기
- 기본 예약 색상 자동 보정과 해제 시 역방향 전환, 다른 사용자 지정 색상 유지
- 원형·사각형·마름모 브러시, 크기 1~64픽셀
- 사각형 선택, 선택 영역 이동·복사·붙여넣기·비우기
- 다른 팔레트로 붙여넣기 전 가장 가까운 색상으로 변환한 결과 확인
- 연결 영역 채우기 및 이미지 전체 동일 색상 채우기
- 직선·사각형·타원, 도형 테두리 두께와 내부 채우기
- 픽셀·팔레트·작성자를 함께 처리하는 문서별 실행 취소·다시 실행
- 확대, 양방향 스크롤바, 픽셀 격자, 원본 픽셀 타일 렌더링
- 실제 그림대화 폴더의 스크롤 가능한 썸네일 목록과 파일명 검색
- 새 타임스탬프 파일 저장 또는 기존 파일 교체, 일괄 저장

## 팔레트

| 자동 보정 끔 | 자동 보정 켬 |
| --- | --- |
| `#FFFFFF` | `#FEFEFE` |
| `#C0C0C0` | `#C1C1C1` |
| `#808080` | `#818181` |
| `#000000` | `#010101` |

보정 체크를 전환하면 위의 색상 쌍만 양방향으로 바뀝니다.
첫 번째 팔레트 색은 새 캔버스의 배경과 선택 영역을 비울 때 사용됩니다.
기존 그림대화의 팔레트·작성자만 바꿀 때는 이미지 픽셀을 다시 양자화하지 않습니다.

## 사용

PNG 열기 또는 드래그 앤 드롭으로 파일을 불러옵니다. 일반 PNG는 작성자 이름을 입력해 변환할 수 있습니다.
기존 그림대화는 그리기 탭에서 바로 편집하며, 일반 이미지의 변환 결과도 편집 가능한 문서로 전환할 수 있습니다.
`chat_sample.png`나 다른 개인 샘플 파일은 필요하지 않습니다.

기본 저장 위치는 Windows에서 제공하는 실제 문서 폴더 아래 `마비노기/그림대화`입니다.
다른 드라이브로 리디렉션된 문서 폴더도 따릅니다. 새 파일 이름은 `chat_날짜_시간_작성자.png`이며 중복 이름은 덮어쓰지 않습니다.
기존 파일 저장은 디스크에서 불러온 그림대화만 원래 경로에 교체합니다.

선택 도구로 사각형을 지정하고 내부를 드래그하면 이동합니다.
선택 영역 복사는 편집기 내부 클립보드를 사용하며, 다른 문서에 붙여넣을 수도 있습니다.
상단 클립보드 버튼은 Windows 클립보드의 이미지를 별도 문서로 불러옵니다.
APNG는 직접 그리기를 지원하지 않습니다. 인터레이스 PNG에 그리면 일반 PNG로 저장합니다.

| 단축키 | 동작 |
| --- | --- |
| Ctrl+N | 새 그림대화 |
| Ctrl+O | PNG 열기 |
| Ctrl+S | 저장 방식 선택 |
| Ctrl+Z | 실행 취소 |
| Ctrl+Y / Ctrl+Shift+Z | 다시 실행 |
| Ctrl+C | 선택 영역 복사 |
| Ctrl+V | 선택 도구에서 내부 복사 영역 붙여넣기, 그 외에는 OS 이미지 불러오기 |
| Delete | 선택 영역 비우기 |
| Escape | 드래그 중인 도형·선택 이동 취소 |

텍스트 입력란에서는 일반적인 텍스트 편집 단축키가 우선합니다.
실행 취소 이력은 최대 50단계이며 메모리 사용량에 따라 줄어듭니다.

## 빌드 및 테스트

Windows용 Rust stable MSVC와 Visual Studio C++ Build Tools가 필요합니다.

```powershell
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo build --release --locked
```

결과: `target/release/mabipng-studio.exe`. `build.bat`로도 빌드할 수 있습니다.
GUI는 Windows 기본 한글 글꼴을 사용합니다. `assets/app_icon.ico`는 애플리케이션에 사용되는 일반 아이콘 리소스입니다.
테스트 이미지는 테스트 코드에서 생성하며 외부 이미지 파일에 의존하지 않습니다.

```powershell
target/release/mabipng-studio.exe --new 128 --author "Test Author"
target/release/mabipng-studio.exe --paint --zoom 6 input.png
```

작성자 해시 규칙은 [AUTHOR_AUTHID.md](AUTHOR_AUTHID.md), 개인정보 제외 범위는 [PRIVACY.md](PRIVACY.md)를 참고해 주시기 바랍니다.
추가 기능 제안은 [EDITOR_IDEAS.md](EDITOR_IDEAS.md)에 정리되어 있습니다.
