# MabiPNG Studio

## 업데이트 확인

시작 시 GitHub의 최신 정식 릴리즈를 백그라운드에서 한 번 확인합니다. 더 높은 버전의 Windows 실행 파일이 있으면 상단 알림에서 릴리즈 페이지를 열 수 있습니다. 안내는 닫을 수 있으며 자동 다운로드나 실행 파일 자동 교체는 하지 않습니다.
네트워크 오류나 요청 제한이 있어도 편집과 저장은 정상 동작하고 다음 실행 시 다시 확인합니다. 확인 요청에는 이미지, 작성자, 로컬 경로가 포함되지 않습니다. 공개 GitHub API 접속 과정에서 일반적인 접속 정보(IP 등)와 프로그램 버전은 GitHub에 전달됩니다.

마비노기 그림대화 PNG를 만들고 변환하고 편집하는 Windows용 Rust GUI입니다.
프로그램 실행에는 Python이나 Rust 설치가 필요하지 않습니다. 소스 빌드에는 Rust 도구 체인이 필요합니다.

## 주요 기능

- 여러 PNG 열기 및 드래그 앤 드롭, Windows 클립보드 이미지 불러오기
- 일반 이미지를 4색·2비트 그림대화 PNG로 변환
- 너비 1~256픽셀, 높이 1~96픽셀의 빈 그림대화 생성
- 기존 그림대화의 팔레트·작성자 편집, author에 대응하는 authid 생성
- 4색 개별 HEX 입력 및 색상 선택기
- 기본 예약 색상 자동 보정과 해제 시 역방향 전환, 다른 사용자 지정 색상 유지
- 원형·사각형·마름모 브러시, 크기 1~64픽셀
- 사각형 선택, 선택 영역 이동·복사·붙여넣기·비우기
- 다른 팔레트로 붙여넣기 전 가장 가까운 색상으로 변환한 결과 확인
- 연결 영역 채우기 및 이미지 전체 동일 색상 채우기
- 직선·사각형·타원, 도형 테두리 두께와 내부 채우기
- 픽셀·팔레트·작성자를 함께 처리하는 문서별 실행 취소·다시 실행
- 확대, 양방향 스크롤바, 픽셀 격자, 원본 픽셀 타일 렌더링
- 실제 그림대화 폴더의 스크롤 가능한 썸네일 목록과 파일명 검색
- 현재 문서의 새 타임스탬프 파일 저장 또는 기존 파일 교체
- 별도 일괄 변환 메뉴에서 여러 원본 PNG의 공통 옵션 변환
- 문서 닫기와 확인 후 디스크 PNG 파일 삭제
- 클립보드 영역 선택 및 기존 캔버스의 크기·위치·배율 조절

## 팔레트

| 자동 보정 끔 | 자동 보정 켬 |
| --- | --- |
| `#FFFFFF` | `#FEFEFE` |
| `#C0C0C0` | `#C1C1C1` |
| `#808080` | `#818181` |
| `#000000` | `#010101` |

보정 체크를 전환하면 위의 색상 쌍만 양방향으로 바뀝니다.
첫 번째 팔레트 색은 새 캔버스의 배경과 선택 영역을 비울 때 사용됩니다.
기존 그림대화의 팔레트·작성자만 바꿀 때는 이미지 픽셀을 다시 양자화하지 않습니다.

## 사용

PNG 열기 또는 드래그 앤 드롭으로 파일을 불러옵니다. 일반 PNG이면 크기와 이미지 배치를 정하는 변환 창이 먼저 열립니다. 작성자와 변환 옵션을 선택하고 적용하면 편집 화면으로 넘어갑니다. 취소하면 해당 가져오기 문서를 닫으며 원본 파일은 유지합니다.
기존 그림대화는 그리기 탭에서 바로 편집하며, 일반 이미지의 변환 결과도 편집 가능한 문서로 전환할 수 있습니다.
`chat_sample.png`나 다른 개인 샘플 파일은 필요하지 않습니다.

기본 저장 위치는 Windows에서 제공하는 실제 문서 폴더 아래 `마비노기/그림대화`입니다.
다른 드라이브로 리디렉션된 문서 폴더도 따릅니다. 새 파일 이름은 `chat_날짜_시간_작성자.png`이며 중복 이름은 덮어쓰지 않습니다.
기존 파일 저장은 디스크에서 불러온 그림대화만 원래 경로에 교체합니다.
기본 화면에는 파일 체크박스가 없으며 저장 버튼과 Ctrl+S는 현재 문서 하나만 저장합니다. 다른 열린 문서는 함께 저장되지 않습니다.

## 일괄 변환

상단 **일괄 변환** 메뉴는 편집 중인 문서와 독립적으로 원본 PNG를 처리합니다.
PNG 추가로 여러 파일을 고르거나 폴더 추가로 그 폴더 바로 아래의 PNG를 불러옵니다. 창에 여러 PNG를 끌어다 놓아도 됩니다.
목록의 X와 목록 비우기는 변환 대상에서만 제외하며 원본 파일을 삭제하지 않습니다.

새 그림대화 작성자, 저장 폴더, 가로 1~256·세로 1~96 크기, 전체 맞춤·채우기, 팔레트와 축소 방식을 지정할 수 있습니다.
기존 그림대화는 기본적으로 작성자·크기·팔레트를 유지하고 예약 색상만 옵션에 따라 보정합니다. 작성자와 크기를 함께 바꾸려면 해당 옵션을 선택합니다.
일반 이미지에는 작성자 이름이 필요합니다. 파일별 성공·실패와 오류 내용을 표시하며, 한 파일의 실패가 나머지 작업을 중단하지 않습니다.
결과는 항상 저장 폴더의 새 파일로 저장합니다. 원본과 이미 존재하는 결과를 덮어쓰지 않으며, 편집 중인 문서의 미저장 내용도 바꾸지 않습니다.
중단을 누르면 현재 처리 중인 파일을 마친 뒤 다음 파일부터 중단합니다.

선택 도구로 사각형을 지정하고 내부를 드래그하면 이동합니다.
선택 영역 복사는 편집기 내부 클립보드를 사용하며, 다른 문서에 붙여넣을 수도 있습니다.
상단 클립보드 버튼은 Windows 클립보드의 이미지를 별도 문서로 불러옵니다.
APNG는 직접 그리기를 지원하지 않습니다. 인터레이스 PNG에 그리면 일반 PNG로 저장합니다.

## 영역 선택 및 캔버스 크기

클립보드 이미지는 먼저 영역 선택 창에 표시됩니다. 이미지 위에서 드래그하여 위치를 옮기고, 마우스 휠 또는 배율 슬라이더로 확대·축소하고, 출력 크기를 조절한 뒤 실제 4색 변환 결과를 확인하고 적용합니다.
출력 크기는 가로 1~256픽셀, 세로 1~96픽셀입니다. 96×96, 128×48, 192×72, 256×96 프리셋과 직접 입력을 지원합니다.
사용자 게임 내 시험 결과에 따른 크기 규칙은 다음과 같습니다.

| 실제 사용 팔레트 색 수 | 가로 | 세로 |
| --- | --- | --- |
| 1~3색 | 1~256픽셀 | 1~96픽셀 |
| 4색 | 128~256픽셀 | 1~96픽셀 |

등록된 팔레트가 4칸이어도 픽셀에서 실제 사용한 항목이 3개 이하면 첫 번째 규칙을 적용합니다.
현재 검사는 사용한 팔레트 인덱스 수를 기준으로 합니다. RGB가 같은 중복 항목도 서로 다른 인덱스라면 별도로 세며, 이 특수한 경우의 게임 판정은 별도 확인이 필요합니다.
변환 적용, 단일 저장, 일괄 변환에서 같은 규칙을 검사하며 조건을 벗어나면 파일을 쓰기 전에 오류를 표시합니다. 가로 128 미만에서 네 번째 색을 사용하게 된 경우 편집 화면에서도 경고합니다.
자동으로 이미지를 늘리거나 색을 없애지는 않습니다. 사용자가 가로를 늘리거나 사용 색상을 3개 이하로 줄인 뒤 저장할 수 있습니다. 0픽셀은 PNG 형식상 허용하지 않습니다.
전체 맞춤, 캔버스 채우기, 원본 배율, 가운데 정렬 버튼을 제공합니다. 작은 캔버스 밖으로 나간 부분은 잘리며 이미지가 차지하지 않은 여백은 지정한 색으로 채웁니다.

변환 옵션에는 이미지에 맞춘 4색 또는 기본 회색조 4색, 픽셀 유지 또는 부드러운 축소, 흰 배경 분리, 예약 색상 자동 보정과 여백 색상이 있습니다.
부드러운 축소에는 Lanczos3 필터를 사용하며 투명 영역은 여백 색상과 합성한 후 처리해 어두운 가장자리를 줄입니다.
작성자 이름은 창 위쪽에서 입력합니다. 취소하면 기존 문서가 바뀌지 않으며 적용하면 별도 편집 문서가 추가됩니다.

기존 문서에서는 미리보기 상단의 자르기 아이콘으로 같은 배치 창을 열 수 있습니다.
그림대화는 원본 팔레트 유지가 기본이며 이 모드에서는 최근접 픽셀 샘플링을 사용해 기존 색상 인덱스와 투명도를 보존합니다. 예약 색상 자동 보정은 별도로 적용됩니다.
캔버스 조절은 한 번의 편집으로 기록되며 실행 취소·다시 실행할 수 있습니다. 적용만으로 디스크 파일이 바뀌지는 않습니다.

## 문서 닫기 및 삭제

미리보기 상단의 X 버튼이나 작업 중 문서의 X 버튼은 문서만 닫으며 디스크의 PNG는 그대로 둡니다. 미저장 내용이 있으면 먼저 확인합니다.
휴지통 모양 버튼은 기존 PNG 파일 삭제를 요청합니다. 폴더 목록의 이미지 우클릭 메뉴에서도 파일 삭제를 선택할 수 있습니다.
파일 이름과 전체 경로를 확인한 후 **영구 삭제**를 누르면 해당 일반 PNG 파일 한 개만 삭제합니다. 폴더와 링크는 삭제하지 않습니다.
이 기능은 Windows 휴지통으로 이동하지 않으므로 복구하거나 실행 취소할 수 없습니다. 저장 중인 파일은 삭제할 수 없습니다.

| 단축키 | 동작 |
| --- | --- |
| Ctrl+N | 새 그림대화 |
| Ctrl+O | PNG 열기 |
| Ctrl+S | 저장 방식 선택 |
| Ctrl+Z | 실행 취소 |
| Ctrl+Y / Ctrl+Shift+Z | 다시 실행 |
| Ctrl+C | 선택 영역 복사 |
| Ctrl+V | 선택 도구에서 내부 복사 영역 붙여넣기, 그 외에는 OS 이미지 불러오기 |
| Delete | 선택 영역 비우기 |
| Escape | 드래그 중인 도형·선택 이동 취소 |

텍스트 입력란에서는 일반적인 텍스트 편집 단축키가 우선합니다.
실행 취소 이력은 최대 50단계이며 메모리 사용량에 따라 줄어듭니다.

## 빌드 및 테스트

Windows용 Rust stable MSVC와 Visual Studio C++ Build Tools가 필요합니다.

```powershell
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo build --release --locked
```

결과: `target/release/mabipng-studio.exe`. `build.bat`로도 빌드할 수 있습니다.
공개 배포용 실행 파일은 `powershell -ExecutionPolicy Bypass -File build-release.ps1`로 빌드합니다. 이 스크립트는 오류 진단 문자열에 포함되는 빌드 머신의 개인 경로를 일반 경로로 치환합니다.
GUI는 Windows 기본 한글 글꼴을 사용합니다. `assets/app_icon.ico`는 애플리케이션에 사용되는 일반 아이콘 리소스입니다.
테스트 이미지는 테스트 코드에서 생성하며 외부 이미지 파일에 의존하지 않습니다.

```powershell
target/release/mabipng-studio.exe --new 128 --author "Test Author"
target/release/mabipng-studio.exe --paint --zoom 6 input.png
target/release/mabipng-studio.exe --frame --author "Test Author" input.png
target/release/mabipng-studio.exe --batch first.png second.png
```

작성자 해시 규칙은 [AUTHOR_AUTHID.md](AUTHOR_AUTHID.md), 개인정보 제외 범위는 [PRIVACY.md](PRIVACY.md)를 참고해 주시기 바랍니다.
추가 기능 제안은 [EDITOR_IDEAS.md](EDITOR_IDEAS.md)에 정리되어 있습니다.
